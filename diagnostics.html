SurfaceStride connection check

This page checks both the published Surface V2 app and its map services. The default walking mode uses OSRM or Valhalla; surface tagging uses the direct OpenStreetMap API. Tests use a fixed public sample location in Austin, never your own location.

A successful walking-router test means the default mode can retrieve pedestrian routes. Gravel surfaces and tiny trails are not verified by those routers. The optional Surface Explorer can still fail if its Overpass provider is unavailable. Aerial-image tests also check that the experimental Satellite Scout can read pixels. If the whole website does not open, go to GitHub Pages settings and ensure source = Deploy from a branch, branch = gh-pages, folder = / (root).
