SurfaceStride connection check

This page tests what your browser can access. No Python, downloads, account setup, or location permission needed. All tests use a fixed public sample location in Austin, not your own location.

A successful test means a service responded; it does not guarantee route quality. Aerial-image tests also check that your browser can read image pixels, which the experimental trail scanner needs. If the whole website does not open, go to GitHub Pages settings and ensure source = Deploy from a branch, branch = gh-pages, folder = / (root).
